# URL55 — GO decision

Necesidad: `Alguien cercano ha intentado suicidarse. ¿Qué hacemos ahora?`

Decisión: GO.

Razones:
1. Intención diferenciada y explícitamente reconocida por recursos públicos españoles para familiares tras un intento.
2. No canibaliza URL54: URL54 cubre preocupación/riesgo antes de una tentativa; URL55 cubre alta, seguridad y seguimiento después de una tentativa.
3. No canibaliza URL53: URL53 es posvención tras una muerte por suicidio.
4. Evidencia suficiente y accionable: Ministerio de Sanidad, Gobierno de Canarias, SAS y contraste OMS.
5. Beneficio social alto y riesgo YMYL controlable con contrato específico y Safety Gate.

Arquitectura temática:
- Riesgo o preocupación: URL54.
- Después de un intento: URL55.
- Después de una muerte: URL53.
